# BARATEC — Landing SRX · GR Hilux 2023+

Landing de amortiguadores BARATEC para Toyota Hilux GR / SRX 2023+.

Tomada como base de la landing Z-71 / Silverado ("Baratec Landing final"), que ya está funcionando y dando resultado. Se mantiene la estructura, los textos y el diseño; se reemplazan imágenes y videos por material específico de la Hilux.

## Stack

Vite + React + TypeScript + Tailwind.

## Desarrollo

```bash
npm install
npm run dev
```
